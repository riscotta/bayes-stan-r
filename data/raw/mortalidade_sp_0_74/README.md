# São Paulo — mortalidade 0–74 (APVP/PRO-AIM × SEADE)

A pasta `resultados_auditados/` contém somente saídas agregadas da E09 e um resumo do bootstrap da E08, congeladas em 2026-10-28. São resultados **condicionados à base E04 provisória**, sujeitos a revisão de compatibilidade territorial e denominadores.
